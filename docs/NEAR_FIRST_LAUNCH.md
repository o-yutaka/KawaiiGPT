# NEAR First Launch Slice

The first public-quality slice is intentionally small:

1. Open app
2. Fast onboarding
3. Permission-aware location setup
4. Nearby list sorted closest-first
5. 10-minute discovery boundary
6. Open profile
7. Start chat
8. NOW feed
9. Mutual Connection
10. Block/Report
11. Push notification
12. Free experience + clearly labeled ad placements
13. Optional trial of premium discovery/visibility features

The product must feel useful before monetization is shown. Premium is an accelerator, not a paywall around the core social loop.

## Trial model
- New users receive a short premium preview.
- One-time first Boost preview.
- Premium features remain clearly labeled during trial.
- Trial end must be explicit; no deceptive renewal.

## Pricing principle
Start slightly below major comparable social/dating subscriptions in each market, then tune by conversion and retention. Prices are remotely configurable and never hard-coded into the UI.

## Privacy principle
No advertiser or affiliate partner receives raw location history. Offer matching uses coarse/consented signals and first-party attribution.

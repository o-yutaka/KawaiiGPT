# NEAR Store Release Gate

## Android
- [ ] release signing configured
- [ ] AAB build
- [ ] privacy policy URL
- [ ] data safety declaration
- [ ] content rating
- [ ] production Supabase environment
- [ ] crash monitoring

## iOS
- [ ] Apple Developer account
- [ ] bundle identifier
- [ ] signing configured through cloud build
- [ ] TestFlight build
- [ ] App Privacy details
- [ ] location permission copy
- [ ] notification permission copy
- [ ] review notes

## Shared
- [ ] account deletion
- [ ] data export/deletion policy
- [ ] block/report flows
- [ ] age gating
- [ ] precise location disclosure
- [ ] ad disclosure
- [ ] affiliate disclosure
- [ ] subscription terms
- [ ] restore purchases
- [ ] support/contact page

## Production gate
No store submission until Cloud RLS, raw-GPS leak, Realtime, device-location, subscription and deletion tests pass.

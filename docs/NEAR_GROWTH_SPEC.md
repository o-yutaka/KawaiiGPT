# NEAR Growth Engine

## Core loop

User joins -> sees nearby people -> chats -> connects -> invites -> local density rises -> discovery becomes more useful -> repeat.

## City metrics
For every city/area calculate:
- active users
- users visible in 10-minute world
- chat starts
- connection rate
- NOW activity
- invite conversion
- D1/D7/D30 retention

## Density score
Density is an internal growth metric, not a public ranking of individual users.

## Campaign engine
Campaigns may target city/area cohorts using privacy-safe aggregate metrics. TikTok/other social campaigns should carry attribution IDs so installs and activation can be measured.

## Launch model
The app is globally available from launch architecture. Growth allocation is dynamically concentrated where density and retention indicate the strongest opportunity.

## Experimentation
Feature flags support controlled tests. Primary metrics:
- activation
- first chat
- first connection
- retention
- reports/block rate
- revenue per active user

Never optimize growth at the expense of safety or privacy.

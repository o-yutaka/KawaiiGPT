# NEAR Agent Waves

## Wave A — Client
Flutter screens, navigation, onboarding, touch effects, location permission, chat, NOW.

## Wave B — Backend
Auth, profiles, conversations, messages, NOW, Connection, moderation.

## Wave C — Security
RLS, raw GPS leak, abuse rate limits, block/report, deletion/export.

## Wave D — Realtime
Messages, presence, NOW updates, notification events.

## Wave E — Growth
Invites, deep links, attribution, city density, experiments.

## Wave F — Revenue
Ads, affiliate offers, Premium entitlements, local sponsored placements.

## Wave G — Intelligence
Recommendation, demand detection, safety intelligence, campaign optimization.

## Rule
Independent tracks may proceed in parallel. Integration is gated by contracts and tests. Cloud-dependent verification remains blocked until Supabase authentication is supplied by the project owner.

# NEAR Onboarding UX

Goal: first useful screen with minimal navigation.

1. Welcome: `近くにいる。今つながる。`
2. Name + age-range/age gate + interests in one compact step.
3. Location permission explanation immediately before OS prompt.
4. Optional notification permission after value is demonstrated.
5. Land directly on NEAR / Closest First.

Never force users through a long carousel of setup screens.

Safety:
- Age policy is explicit before discovery.
- Location permission can be denied; app remains usable with reduced discovery.
- Privacy explanation states that exact GPS is not shown to other users.
